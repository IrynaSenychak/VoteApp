# VoteApp

VoteApp — це сучасна платформа для організації та проведення голосувань всередині організацій за допомогою технологій блокчейн для гарантування прозорості, надійності та незмінності результатів прийняття колективних рішень.

<br>Код фронтенду проєкту - [VoteApp Frontend](https://github.com/alexolashyn/vote-app-client)
